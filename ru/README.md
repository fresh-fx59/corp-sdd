# Стартовый комплект Corporate SDD

Комплект устанавливает системное хранилище SDD для проекта и процесс OpenSpec
для каждого репозитория. После зеркалирования нужных бинарных файлов и npm-пакета
он работает в закрытой сети.

Начните с [`docs/SETUP.md`](docs/SETUP.md). Это единственная инструкция для
установки и обновления. Ежедневная работа и восстановление описаны в
[`docs/OPERATIONS.md`](docs/OPERATIONS.md).

Сам процесс описан двумя файлами, и ни один из них ничего не устанавливает:
[`docs/FLOW.md`](docs/FLOW.md) — таблица из семи этапов, по строке на каждую команду `corp-*`;
[`docs/FLOW-TABLE.md`](docs/FLOW-TABLE.md) — большая таблица: вызов OpenSpec, дисциплина
Superpowers, реально запускаемые скрипты, выходное условие и ценность на каждом шаге;
[`docs/FLOW-SCHEMA.md`](docs/FLOW-SCHEMA.md) — те же семь этапов одной схемой на экран.

## Итоговая структура

```text
<workspace>/
├── corp-sdd/                  # этот комплект: настройки, команды, навыки, скрипты
└── system-store/              # отдельный Git-репозиторий
    ├── project-repositories.json
    ├── .gitmodules
    ├── openspec/              # межрепозиторные контракты и ADR
    ├── tools/
    └── submodules/
        ├── <repository-a>/
        └── <repository-b>/
```

Если доступен MCP проекта, список репозиториев берётся из него. Тот же
нормализованный JSON можно заполнить вручную, поэтому MCP не является зависимостью
установщика. Комплект содержит собственные навыки `corp-*`. Внешний Superpowers
не требуется.

## Состав

- `system-store-template/`: обычные файлы для соседнего системного хранилища;
- `scripts/tools/`: синхронизация подмодулей, контроль Git-состояния, проверки и индексы;
- `commands/`: семь шаблонов Corp-команд с явными вызовами OpenSpec;
- `skills/`: шесть самостоятельных Corp-навыков;
- `templates/`: шаблоны исследования, ADR, контракта, фактов порта и ветвления;
- `config/`: пример списка репозиториев и пример lefthook;
- `slides/`: доклад и его исходник для правки.

Приёмочные наборы, которые проверяют комплект, лежат в `tests/` в корне репозитория,
рядом с двумя языковыми копиями, и запускаются против поставляемых файлов.

Шаблон специально не содержит вложенного Git-репозитория. Установка копирует
его рядом с `corp-sdd`, инициализирует Git и не изменяет существующее хранилище.
