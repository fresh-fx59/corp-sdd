description: Черновик делта-спеки из истории трекера через интервью (поток аналитика)
---
Вы составляете черновик делта-спеки для истории {{args}}.
1. Получите историю и связанные wiki-страницы через MCP-инструменты трекера/wiki.
2. Прочитайте openspec/index.md, затем ТОЛЬКО те живые спецификации, которых касается история; следуйте скилу
   corp-drill-down (центральный каталог → индекс репозитория → живые файлы; репозиторий побеждает; ≤3 переходов).
3. Проверьте каждый факт контракта по живому коду (встраивайте директивами <!-- embed -->).
4. Проинтервьюируйте аналитика — ОДИН вопрос за раз, предпочтительно с вариантами выбора — пока
   требования и сценарии Given/When/Then не станут однозначными.
5. Создайте изменение OpenSpec (proposal + делта-спека) через поток opsx.
   Добавляйте каждый проверенный факт строкой-указателем в research.md (path#Lx-Ly + вывод).
6. Запустите: bash tools/verify-docs.sh — правьте, пока не станет зелёным.
7. ПЕРЕДАЧА (сделайте это сами — аналитик никогда не касается git): создайте/переключитесь на
   ветку изменения, закоммитьте папку изменения, запушьте и откройте (или обновите) PR со спекой.
   Опубликуйте сводку по спеке + ссылку на PR обратно в историю трекера. НЕ создавайте design.md
   и tasks.md (планирование происходит на этапе pull).
