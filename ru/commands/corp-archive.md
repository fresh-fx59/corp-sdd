Заархивируйте изменение {{args}}. Следуйте скилу corp-verification (свидетельство для каждого шага ниже).
Предусловие: PR изменения СМЁРЖЕН и вы на обновлённом main —
проверьте оба; если нет, ОСТАНОВИТЕСЬ.
1. Запустите шаг архивации OpenSpec (opsx archive) — делта сворачивается в openspec/specs/.
2. Составьте ADR из решений изменения (proposal «почему» + открытия research.md + любые
   поправки к спеке), используя шаблон из harness-пакета; запишите в openspec/adr/NNNN-<slug>.md
   (следующий свободный номер). ADR только-на-добавление: никогда не редактируйте принятый ADR — замещайте его.
3. Перегенерируйте индекс: node tools/gen-index.mjs
4. Запустите: bash tools/verify-docs.sh — должно быть зелёным.
5. Закоммитьте («archive <change-id>: living spec + ADR + index») и запушьте. Каталог store подхватит
   это при следующей агрегации — никаких ручных правок store, никогда.
6. Опубликуйте однострочную заметку о завершении в историю трекера через MCP.
