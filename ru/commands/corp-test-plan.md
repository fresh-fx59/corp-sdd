---
description: Превратить сценарии одобренной делта-спеки в чек-лист ручного тестирования (поток тестировщика)
---
Постройте план ручного тестирования для изменения {{args}}.
1. Прочитайте сценарии делта-спеки И разделы живой спеки, которые она изменяет (регрессии живут там).
2. Для каждого сценария создайте пункт чек-листа: предусловия (тестовые данные, роль пользователя, состояние системы),
   шаги, ожидаемый результат, ID требования (напр. R3). Добавьте регрессионные пункты для ИЗМЕНЁННЫХ требований.
3. Добавьте раздел «стоит исследовать»: краевые области, которые сценарии не покрывают (переходы состояний,
   права доступа, конкурентность, пустые/переполненные входы) — предложения для тестировщика, чётко помеченные.
4. Опубликуйте чек-лист в историю трекера через MCP. Не отмечайте ничего как пройденное — выполнение
   плана — работа тестировщика, и его дополнения важнее ваших.
